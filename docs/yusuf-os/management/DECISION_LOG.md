# Yusuf OS Decision Log

## D-001 — Local repository and persistent memory are primary truth

- **Date:** 2026-08-27
- **Decision:** Use internally consistent local commits, current code, tests, and chronological memory over the older remote branch state.
- **Reason:** Local HEAD contains 29 later commits; the remote-only patch mainly preserves `.claude/launch.json`, which local history intentionally omitted.
- **Consequence:** No reset, rebase, push, or force operation is authorized.

## D-002 — Do not restart V1 phases S–AE

- **Date:** 2026-08-27
- **Decision:** Treat S–AE as implemented and verified by test, with live claims kept narrower.
- **Reason:** Current gate/history, commits, and fresh regressions support completion.
- **Consequence:** New work begins with commissioning, not “Phase AF.”

## D-003 — Commission before integrating

- **Date:** 2026-08-27
- **Decision:** First prove real `/os`, voice, Chrome attachment, and a read-only browser observation; then select one governed mutation.
- **Reason:** This closes the largest gap between deterministic V1 evidence and daily operational trust.
- **Consequence:** Gmail and other integrations remain NEXT until the boundary is proven.

## D-004 — Preserve staff; grow capabilities and workflows

- **Date:** 2026-08-27
- **Decision:** Add no Agent for the current roadmap.
- **Reason:** Existing staff already own commissioning, inbox, career, marketing, monitoring, research, engineering, review, and founder work.
- **Consequence:** Any future Agent proposal must prove an ownership gap and maintenance value.

## D-005 — Treat Agent Workspace as a distinct product experience

- **Date:** 2026-08-27
- **Decision:** Keep `/os` as the global Command Center and plan a focused Agent Workspace as a separate NEXT slice.
- **Reason:** The current Agent drawer and voice dock do not satisfy the complete workspace layout, but commissioning feedback should shape it.

## D-006 — No cloud program yet

- **Date:** 2026-08-27
- **Decision:** Keep Yusuf OS local-first and single-user.
- **Reason:** No evidenced need currently outweighs the security, cost, and operating-boundary expansion.

## D-007 — Use honest operational metrics only

- **Date:** 2026-08-27
- **Decision:** Measure concrete task, verification, approval, reconciliation, fallback, duration, scheduler, monitoring, external mutation, and intervention events.
- **Reason:** Synthetic productivity percentages would create surveillance theater, not product learning.
